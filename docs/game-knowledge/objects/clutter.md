# Clutter Mods

Tiny Glade's official modding support allows players to add new **clutter objects** to the game using `.glb` files.

These mods are created and managed through Tiny Glade's built-in modding tools and can be shared through the **Steam Workshop**.

Unlike the older asset-replacement workflow, clutter mods do **not** require editing Tiny Glade's built-in JSON meshes or using the community Blender JSON importer/exporter. Any 3D modelling software capable of exporting compatible glTF 2.0 `.glb` files can be used.

For the complete and up-to-date workflow, including file requirements, materials, importing, testing, and publishing, see the official [Tiny Glade modding guide](https://pouncelight.games/tiny-glade/info/modding/).

!!! tip

    Use the official developer documentation as the primary reference for clutter mods. Tiny Docs may provide additional examples and community discoveries as the modding system develops.
